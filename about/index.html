About this archive

📌 Pilot corpus. This site currently presents 2 fully digitized issues (8 pages) out of an estimated 14,000+ pages held by SUBRAS spanning 1924–present. It exists to demonstrate the digitization pipeline end-to-end — OCR, translation, entity extraction, provenance anchoring, standards-compliant export — ahead of a funding application to digitize the full run. Figures on this site (issue counts, person/location indices) describe the pilot corpus, not the complete newspaper archive.

The newspaper

Khliborob (Хлібороб, "The Farmer") was founded in Porto União, Paraná, Brazil in 1924 by the Ukrainian poet Petro Karmansky. It is one of the longest-running Ukrainian diaspora newspapers in the world, published continuously to the present day (under the name O Lavrador since the Vargas-era forced Portuguese transition of 1940–46). It is published by SUBRAS (Sociedade Ucraniana do Brasil) in Curitiba.

The GPU discovery

Four declassified documents from the Branch State Archives of the Ukrainian Foreign Intelligence Service (SZRU) demonstrate that Khliborob circulated within a transnational Ukrainian political network connecting Curitiba, São Paulo, and Istanbul during the Holodomor period (1929–1933). GPU intelligence summaries compiled for Japanese diplomatic services in November 1932 cite the newspaper as a source for information about executions of starving peasants in Soviet Ukraine.

These documents name real individuals under surveillance during a period of political persecution. They are reproduced here as declassified historical intelligence records released by SZRU (published 23 November 2025) for scholarly research; readers should treat the identities involved with the same care historians apply to any archive documenting political repression of named persons.

Methodology & limitations

Page images are transcribed and translated (Ukrainian → English, and Portuguese where the original is already in Portuguese) using Gemini 2.5 Flash vision OCR. The model flags tokens it is not confident about; these appear on each issue page as highlighted words with the reason for the flag, so uncertain readings stay visible rather than silently smoothed over. No independent human-transcription accuracy study has been run yet on this pilot corpus — the highlighting is a transparency mechanism, not a validated error rate. Machine translation of 1920s diaspora Ukrainian and period Portuguese carries the usual risks of idiom loss and anachronistic phrasing; researchers doing close reading should treat the English/Portuguese columns as a navigation aid and verify against the Ukrainian original (or the page scan) before quoting.

Standards & interoperability

Each digitized page has an IIIF Presentation 3.0 manifest (linked from its issue page) so the scans can be opened in Mirador, Universal Viewer, or any other IIIF-compatible tool. Metadata for all issues is also published as a Dublin Core / OAI-PMH-format static export — a snapshot rather than a live query endpoint, since the site itself is static-hosted, but structured for reuse by aggregators such as Europeana or the Deutsche Digitale Bibliothek. TEI, ALTO, and METS XML are also generated per page by the pipeline.

The pipeline

This archive was built using an open-source digitization pipeline developed at the University of Münster. Issues are processed using Gemini 2.5 Flash for OCR and bilingual (Ukrainian/English) transcription, stored permanently on IPFS via Pinata, and cryptographically anchored on the Polygon blockchain. The pipeline source code is available at GitHub.
